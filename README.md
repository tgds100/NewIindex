# SuperEdge 金丝雀 (v1.9.2)

高性能边缘隧道IP代理系统。采用多文件模块化设计，支持多接入路径、丰富的出站代理隧道（ProxyIP / SOCKS5 / HTTP）、智能下行模式调优，以及安全双层隔离的配置面板。

---

## 📂 文件结构

项目由以下 6 个核心文件组成：

| 文件名 | 职责说明 |
| --- | --- |
| **`config.js`** | 全局配置、三档性能 Profile 定义、启动期强校验 |
| **`core.js`** | 模块级常量、VLESS 协议解析层、出站层（SOCKS5 / HTTP 隧道 / 智能竞速） |
| **`session.js`** | 缓冲合包、下行数据流泵、单连接状态机与内存回收 |
| **`web.js`** | 门面站点生成：伪装主页 / robots.txt / sitemap.xml / favicon / 404 页面 |
| **`api.js`** | 门面 API 响应：`/api`、`/telemetry`、`/push` 的结构化 JSON 数据 |
| **`index.js`** | 入口路由分发、策略路径解析、面板渲染与动态注入 |

## ⚙️ Path 格式与参数说明

接入路径支持配置多条（见 `CFG.pathPrefix`），面板中可下拉自由选择。URL 参数支持以下组合：

* **纯直连模式**：`?ed=2560`
* **ProxyIP 备用模式**：`?ed=2560&ip=1.2.3.4:443`
* **局部 SOCKS5 代理**：`?ed=2560&s5=<URL-encoded "socks5://user:pass@host:port">`
* **局部 HTTP 代理**：`?ed=2560&h=<URL-encoded "http://user:pass@host:port">`
* **全局 SOCKS5 代理**：`?ed=2560&g5=<URL-encoded "socks5://user:pass@host:port">`
* **全局 HTTP 代理**：`?ed=2560&gh=<URL-encoded "http://user:pass@host:port">`

### 🚀 下行传输模式 (`&ll=`)

在任意 Path 后追加参数可切换下行性能档位：

* `&ll=0` （默认/不填）：**均衡模式** —— 兼顾吞吐量与内存开销。
* `&ll=1` ：**低延迟激进版** —— 极速响应，适合 SSH 远程连接、游戏、实时通信等场景。
* `&ll=2` ：**高速下载激进版** —— 专为 Google Play、AppStore、网盘大文件下载调优的高吞吐模式。

## 🔒 面板访问（双层安全隔离）

系统内置了双层安全关卡，防止未经授权的扫描与访问：

1. **关卡 1（路由层）**：直接访问根路径返回纯文本 404 页面；必须访问 `/?panel=<panelKey>` 才会下发包含面板入口的 502 页面。
2. **关卡 2（加密层）**：输入正确的 PIN 码后，通过 AES-GCM 解密并在前端动态注入配置面板 DOM。

## 📋 版本更新历史 (v1.8.6 - v1.9.2)

* **v1.8.6**：引入三档下行模式（`ll=0/1/2`），参数归位至 `PROFILES`，移除端口自动判定，面板改为下拉选择。
* **v1.8.7**：针对 5-20 人轻量场景的极致性能优化：
* 移除冗余结构化日志，大幅降低 CPU 开销。
* 失败连接缓存上限 `failCacheMax` 由 512 缩减至 128。
* `ll=2` 模式下行阈值微调（`dnHigh`：8MB → 7MB，`dnLow`：2MB → 1.75MB）。
* 增强 `activeSessions` 的 `try/finally` 异常保护与 Socket 泄漏修复。


* **v1.8.8**：面板文案与交互全面重写：
* 代理类型升级为 6 项下拉菜单，支持动态展开场景、优缺点与适用说明。
* 传输模式提供 3 项下拉及详细参数对比表（合并/超时/内存/代价）。
* 优化字段标签、格式示例与使用引导。
* 引入 PIN 输入框显示/隐藏切换（👁）及移动端响应式全宽适配。


* **v1.8.9**：生成结果新增 **③ 扫码导入**：
* 前端通过 `qr.tgds.eu.org` 动态生成 SVG 二维码（`level=M` / `size=320`）。
* 提供面板内缩略图，支持点击全屏放大以便手机客户端直接扫描。
* 具备平滑降级机制，二维码加载失败时自动降级为文字提示，不影响链接复制。


* **v1.9.0**：裸版策略改为标准 404：
* 独立的无脚本、无交互 404 纯文本页面，增强隐蔽性。
* 除指定的 `/?panel=<panelKey>` 外，所有普通请求一律返回 404。
* 面板版维持原有的 502 状态码与 PIN 解锁流程。


* **v1.9.1**：多接入路径支持：
* `pathPrefix` 变更为数组格式，入口支持逐一前缀匹配，任一路径均可正常握手。
* 面板新增“接入路径”下拉选择器，生成的订阅链接与二维码随所选路径动态联动。
* 启动校验机制：自动拒绝包含 `?` 或 `#` 的路径条目，防止静默死配置。


* **v1.9.2**：面板 UI 深度抛光与文案精准化（方案 A）：
* **设计 Token 化**：表面、灰阶、圆角、阴影、焦点光圈全面收敛为 CSS 变量。
* **暗色模式适配**：完美跟随系统 `prefers-color-scheme`，502 错误页面背景同步变色。
* **二维码专项优化**：保持白底黑码以确保扫码器兼容性，外框采用现代卡片化设计。
* **控件统一**：统一为 34px 高度、8px 圆角及 focus 柔光圈；移动端触控目标扩大至 $\ge 40\text{px}$。
* **参数修正**：修正 `LL_HINT` 与 `PROFILES` 不符的参数说明（48KB 一帧 / 1s 切换 / 3s 超时）。
* **文案精修**：对 ② 标题、接入路径、代理类型等共 11 处文案进行专业化精准润色。
